# 前端界面设计文档

> AI Agent 日程与任务协同助手  
> 技术栈：React 18 + TypeScript + Ant Design 5 + Zustand + React Router 6  
> 文档版本：V1.0

---

## 界面总览

| 序号 | 页面 | 路由 | 说明 |
|------|------|------|------|
| 1 | 登录页 | `/login` | 用户名密码登录 |
| 2 | 首页总览 | `/dashboard` | 今日任务、日程、统计卡片 |
| 3 | 目标输入页 | `/goals/new` | 自然语言输入 + Agent 解析反馈 |
| 4 | 追问澄清页 | `/goals/:id/clarify` | 多轮对话式追问 |
| 5 | 确认目标页 | `/goals/:id/confirm` | 确认解析结果 |
| 6 | 排期预览页 | `/goals/:id/plan` | 查看排期方案 + 冲突标识 |
| 7 | 任务列表页 | `/tasks` | 任务筛选 + 列表 + 状态操作 |
| 8 | 任务详情页 | `/tasks/:id` | 任务详情 + 操作记录 |
| 9 | 周报页 | `/report` | 周报统计 |
| 10 | 提醒设置页 | `/reminders` | 提醒列表 + 编辑 + 删除 |
| 11 | 个人设置页 | `/settings` | 全局提醒偏好设置 |

### 1. 登录页

**路由**：`/login`

**布局**：居中卡片式

```
┌──────────────────────────────────────────────┐
│                                              │
│            🤖 AI 日程协同助手                │
│         智能规划你的每一天                    │
│                                              │
│       ┌──────────────────────────┐           │
│       │  用户名                   │           │
│       │  [____________________]  │           │
│       │                          │           │
│       │  密码                     │           │
│       │  [____________________]  │           │
│       │                          │           │
│       │  [      登  录      ]    │           │

│                                              │
│         没有账号？联系管理员                  │
│                                              │
└──────────────────────────────────────────────┘
```

**交互逻辑**：
- 输入用户名密码 → 点击登录 → 调 `POST /api/v1/auth/login`
- 成功：存储 Token（localStorage）→ 跳转首页
- 失败：错误提示（用户名或密码错误）
- 回车键快速登录
- 空值校验：按钮置灰不可点

```
│  │                                                  │   │

│                                                          │
│  🎤 语音输入（扩展功能）                                │
│                                                          │
│  ┌──────────┐                                           │
│  │ 开始解析 │                                           │
│  └──────────┘                                           │

│  │                                                  │   │
│  │  ┌──────────┐  ┌──────────┐                     │   │
│  │  │ 确认目标 │  │ 手动修改 │                     │   │
│  │  └──────────┘  └──────────┘                     │   │
│  └──────────────────────────────────────────────────┘   │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**交互流程**：

```
输入自然语言
    │
    ▼
点击"开始解析"
    │
    ▼
调用 POST /api/v1/goals/parse
    │
    ├── needsClarification = true
    │   → 跳转 /goals/:id/clarify
    │
    └── needsClarification = false
        → 停留当前页，展示解析反馈卡片
        → 可"确认目标"或"手动修改"
```

**异常处理**：
- 输入为空：按钮不可点
- 网络异常：提示"网络连接失败，请重试"
- 解析超时（30s）：提示"解析超时，请简化描述后重试"
- 低置信度：黄色警告"部分信息不确定，建议确认后继续"

**数据来源**：`POST /api/v1/goals/{id}/reply`

**布局**：对话式交互

```
┌──────────────────────────────────────────────────────────┐
│  💬 补充信息    ← 返回目标页                第 2/5 轮   │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  ┌──────────────────────────────────────────────────┐   │
│  │ 📋 已识别信息                                    │   │
│  │                                                  │   │
│  │ · 目标：新人培训汇报                            │   │
│  │ · 截止：2026-08-01                              │   │
│  │                                                  │   │
│  └──────────────────────────────────────────────────┘   │
│                                                          │
│  对话区域                                               │
│  ┌──────────────────────────────────────────────────┐   │
│  │                                                  │   │
│  │  👤 帮我安排下周五前完成新人培训汇报              │   │
│  │                                                  │   │
│  │  🤖 好的，关于这个目标我需要了解更多：            │   │
│  │     1. 具体需要完成哪些子事项？                   │   │
│  │     2. 每个事项大概需要多长时间？                 │   │
│  │     3. 事项之间有依赖关系吗？                     │   │
│  │                                                  │   │
│  │  👤 材料整理2天，PPT初稿1天，评审修改1天，        │   │
│  │     最终彩排半天。PPT需要等材料整理完             │   │
│  │                                                  │   │
│  │  🤖 明白了，我再确认一下...                       │   │
│  │     追问：评审修改是否需要邀请其他人参与？        │   │
│  │                                                  │   │
│  └──────────────────────────────────────────────────┘   │
│                                                          │
│  ┌──────────────────────────────────────────────┐       │
│  │  需要邀请导师和同组同事一起评审              │       │
│  └──────────────────────────────────────────────┘       │
│                          ┌────────┐                      │
│                          │  发送  │                      │
│                          └────────┘                      │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

**交互逻辑**：
- 上部分：已有解析结果只读展示卡片
- 中部：对话气泡，用户输入右侧、Agent 问题左侧
- 下部：输入框 + 发送按钮
- 每次发送调用 `POST /api/v1/goals/{id}/reply`
- 当 `needsClarification = false` 时 → 弹窗"解析完成，是否查看排期？"→ 跳转排期
- 达到最大轮次（5轮）→ 强制结束，提示"已达到最大追问轮次，将以当前信息生成排期"

**状态流转**：

```
第1轮 → 第2轮 → ... → 第5轮(强制结束)
  │
  └── 任意轮次 needsClarification=false → 解析完成 → 跳转排期
```

- 勾选完成 → 弹出确认 → `PUT status = DONE`
- 每项右侧三个点菜单：开始执行 / 标记完成 / 重新规划 / 删除
- 列表支持分页（10条/页）
- 空状态：插图 + "暂无任务，去创建一个吧？" + 按钮

**筛选联动**：
- 切换状态下拉 → 重新请求 `GET /api/v1/tasks?status=xxx`
- 搜索防抖输入 500ms 后前端过滤
